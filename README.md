Este repositorio compila proyectos de **Inteligencia Territorial**, **Automatización de Reportes** y **Análisis Estadístico**, aplicando tecnologías de código abierto a problemáticas sociales y de gestión pública.

## 📂 Estructura del Portafolio

### 1. [Herramientas Interactivas (R Shiny)](./proyectos_r_shiny)
Desarrollo de aplicaciones web para la visualización de datos y toma de decisiones.
* **`app.R`**: Monitor de Inteligencia Territorial para la Región de Los Lagos. Integra datos CASEN y mapas interactivos con `Leaflet` para analizar estructura de clases y pobreza multidimensional.
* **`encuesta.R`**: Aplicación de encuestas dinámicas con lógica condicional (`ShinyJS`) para estudios de opinión pública y elecciones.
* **`scouting.R`**: Aplicación de scouting de jugadores del fútbol chileno.
