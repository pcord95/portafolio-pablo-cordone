# Pablo Cordone Sánchez

Sociólogo (Universidad de La Frontera). Analista de scouting, videoanálisis y datos de fútbol.

Este repositorio reúne tres proyectos propios. Cada uno se muestra de forma parcial: la explicación, la metodología y una parte del código o un demo. Los datos completos y las piezas de cálculo centrales no se publican.

| Proyecto | De qué trata | Qué hay aquí |
|---|---|---|
| [ETData](./etdata) | Sistema de análisis y scouting de fútbol: base de datos propia, indicadores, encaje táctico, videoanálisis e informes. | Explicación, metodología y un [demo en vivo](https://pablocordone.shinyapps.io/etdata-demo/) con una muestra de datos. |
| [SIG electoral](./sig-electoral) | Análisis geográfico de resultados electorales en la Región de Los Lagos, por comuna y por local de votación. | Explicación y código de la aplicación (sin datos). |
| [Kimberley N5](./kimberley) | Terminal local de análisis táctico-sociológico en vídeo para un club amateur. | Explicación y código de la aplicación (sin vídeos ni registros). |
